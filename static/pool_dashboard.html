How to Mine?

connect miner at …
Expand
1. Install the miner github
cargo install snap-coin-miner
2. Create miner.toml
[node] address = "" [miner] public = "YOUR_PUBLIC_WALLET_ADDRESS" [threads] count = -1 # -1 for max threads
Replace YOUR_PUBLIC_WALLET_ADDRESS with your actual Snap Coin public address
3. Run the miner
snap-coin-miner --pool
